# O que é OpenGL

Para nos comercamos com OpenGL, precisamos entender primeiramente do que isso se trata. O OpenGL ela é basicamente uma API ou Interface de Programação de Aplicativos, ela nos fornece um grande conjunto de ferramentas, que podemos usar para criar graficos ou imagens.

# Perfil principal x Modo imediato
Há muito tempo atraas, usar o OpenGL era praticamente desenvolver em "modo imediato", ele era um metodo muito mais facil de usar para a criacao de desenhos em graficos. Alggumas coisas ruindo daquilo, era que os desenvolvedores eles nao tinam muito controle sobre como o OpenGL reaalizava os calculos. Com o passar dos anos, os desenvolvedores passaram a querer mais flexiblidade e as especificacoes ser tornaram mais flexiveis. *Perfil principal*
Nessa aqui o buraaco e mais em baixo, ao usarmos esse modo do opengl, temos que aprender praticas modernas. Sempre quando tenta usar algumas das funcoes obsoletas do open, ele gerava um erro, assim, interropendo a renderizacao.
